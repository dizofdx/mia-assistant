## 🌟 Возможности Мии

- 🎙️ **100% Офлайн голос** — распознавание речи (Whisper) + живой эмоциональный синтез речи (Silero TTS), работает без интернета и задержек!
- 🧠 **Умный мозг** — локальная модель (Ollama Qwen 2.5) или сверхмощный облачный DeepSeek V4 с вызовом 60+ системных инструментов.
- 📱 **Личный Telegram-бот** — управляй домашним компьютером прямо со смартфона из любой точки планеты (текстом или голосовыми!).
- 🌐 **Киберпанк Веб-панель Astra** — мониторинг процессора/ОЗУ/дисков, статус ассистента, интерактивный чат и визуальный редактор сценариев.
- 🎵 **Мультимедиа & Музыка** — запуск Яндекс Музыки («Моя волна»), поиск на YouTube, переключение треков, умное приглушение звука при разговоре (Audio Ducking).
- 💻 **Полный контроль над Windows** — запуск любых программ, свернуть/закрыть окна, сделать скриншот, заблокировать ПК.
- ⚡ **Визуальные сценарии** — автоматизация действий в один клик или по одной голосовой фразе (например, режим «Отдых»).
- 📲 **PWA Мобильный пульт** — веб-приложение для смартфона по локальной Wi-Fi сети.

## 🚀 Быстрый старт: Установка

### Вариант 1: Установка в 1 клик через Инсталлятор (Рекомендуется)
1. Скачай готовый инсталлятор **`MiaInstaller.exe`** из [релизов репозитория](https://github.com/dizofdx/mia-assistant/releases) или корня проекта.
2. Запусти файл `MiaInstaller.exe` и следуй подсказкам установщика.

#### 1. Требования
- **ОС:** Windows 10 или 11 (64-bit)
- **Python:** 3.11 или 3.12+ ([python.org](https://www.python.org/downloads/))

```bash
pip install -r requirements.txt
```

## 🤖 Пошаговая инструкция: Как создать и подключить СВОЕГО бота

С Мией ты получаешь собственного персонального бота в Telegram, через которого можно отправлять голосовые команды, получать скриншоты экрана ПК, запускать программы и музыку, где бы ты ни находился.

### Шаг 1: Создание бота в Telegram через @BotFather
1. Открой Telegram и введи в поиске **`@BotFather`** (официальный бот с синей галочкой) либо перейди по ссылке: [t.me/BotFather](https://t.me/BotFather).
2. Нажми кнопку **«Запустить»** (или отправь `/start`).
3. Отправь команду:
   ```text
   /newbot
   ```
4. Введи отображаемое имя для своего ассистента (например: `Моя Мия` или `JARVIS AI`).
5. Введи юзернейм бота на латинице, который обязательно оканчивается на `_bot` (например: `MyMiaSmart_bot` или `AlexPersonalMia_bot`).
6. **Готово!** `@BotFather` пришлет сообщение с HTTP API токеном вида:
   ```text
   1234567890:AAH_ABCdef1234567890XYZ_Example
   ```
   > ⚠️ **Сохрани этот токен!** Он потребуется на Шаге 3.

---

### Шаг 2: Получение твоего Telegram ID (Защита от посторонних)
Чтобы посторонние пользователи в Telegram не могли управлять твоим компьютером, Мия слушается **только своего владельца** (твой `ADMIN_ID`).

1. Найди в Telegram бота **`@userinfobot`** (или `@getmyid_bot`).
2. Нажми **«Запустить»** (`/start`).
3. Бот ответит твоим профилем. Найди строку:
   ```text
   Id: 123456789
   ```
4. Скопируй эти цифры — это твой персональный Telegram ID.

---

### Шаг 3: Настройка `config.py`
В корне проекта находится файл-шаблон `config.example.py`.

1. Создай рабочий файл конфигурации:
   ```powershell
   # В PowerShell:
   Copy-Item config.example.py config.py

   # Или в командной строке CMD:
   copy config.example.py config.py
   ```
2. Открой созданный `config.py` в любом текстовом редакторе (Блокнот, VS Code, Notepad++).
3. Найди строки Telegram и вставь свои полученные данные:
   ```python
   # Твой токен от @BotFather:
   TG_TOKEN = "ВСТАВЬ_СЮДА_СВОЙ_ТОКЕН"

   # Твой числовой ID от @userinfobot (число БЕЗ кавычек!):
   ADMIN_ID = 123456789
   ```
4. Сохрани файл.

---

### Шаг 4: Выбор и настройка «Мозга» ИИ (LLM)

#### 🔹 Вариант А: 100% Локально и бесплатно через Ollama (Рекомендуется)
1. Скачай и установи **[Ollama для Windows](https://ollama.com/download/windows)**.
2. Открой терминал и скачай быструю модель Qwen 2.5:
   ```bash
   ollama run qwen2.5:3b-instruct
   ```
   *(Если у тебя мощная видеокарта от 8GB VRAM, можно взять модель умнее: `ollama run qwen2.5:7b-instruct`)*
3. В `config.py` по умолчанию уже всё настроено на Ollama:
   ```python
   LLM_BASE_URL = "http://127.0.0.1:11434/v1"
   LLM_API_KEY  = "ollama"
   LLM_MODEL    = "qwen2.5:3b-instruct"
   ```

#### 🔹 Вариант Б: Облачный DeepSeek API (Быстро и недорого)
Если не хочешь нагружать свой ПК:
1. Зарегистрируйся на [platform.deepseek.com](https://platform.deepseek.com) и получи API-ключ.
2. В `config.py` укажи:
   ```python
   LLM_BASE_URL = "https://api.deepseek.com"
   LLM_API_KEY  = "sk-твой_ключ_от_deepseek"
   LLM_MODEL    = "deepseek-chat"
   ```

### Шаг 5: Кастомизация бота под себя (Имя, Голос, Характер)

Ты можешь легко превратить Мию в сурового мужского помощника **JARVIS** или оставить задорной аниме-тян:

1. **Имя голосовой активации (Хотворд)** в `config.py`:
   ```python
   # Для Мии:
   HOTWORD_NAMES = ["мия", "миечка", "мика", "mia"]

   # Для Джарвиса:
   HOTWORD_NAMES = ["джарвис", "jarvis"]
   ```

2. **Голос (Silero TTS)** в `config.py`:
   ```python
   # "xenia" — задорный женский/аниме голос
   # "aidar" — уверенный мужской голос (Джарвис)
   # "baya"  — мягкий спокойный женский голос
   SILERO_SPEAKER = "xenia"
   ```

3. **Характер и поведение (`SYSTEM_PROMPT`)**:
   Отредактируй текстовый промпт `SYSTEM_PROMPT` в `config.py`, чтобы задать ассистенту любые правила поведения, любимый юмор или стиль общения.

## 📱 Мобильный пульт управления (PWA)

Ты можешь открывать веб-панель управления со смартфона по домашней сети Wi-Fi:
1. Узнай локальный IP-адрес своего компьютера в сети (команда `ipconfig` в терминале, например `192.168.1.105`).
2. Открой браузер на телефоне (Safari / Chrome) и перейди по адресу:
   ```text
   http://192.168.1.105:8000
   ```
3. В меню браузера нажми **«На экран "Домой"»** / **«Установить приложение»**.
4. Теперь у тебя на экране телефона полноценный пульт с кнопками сценариев, мониторингом ПК и чатом!

## 🎙️ Примеры команд

| Команда (голосом или в Telegram) | Что делает Мия |
|-----------------------------------|----------------|
| *«Мия, включи мою волну»* | Запускает Яндекс Музыку в браузере |
| *«Мия, сделай скриншот»* | Делает скриншот экрана (в Telegram сразу присылает фото) |
| *«Мия, открой YouTube»* | Запускает YouTube в браузере |
| *«Мия, запусти сценарий отдых»* | Выполняет цепочку: открывает YouTube, включает музыку и приглушает свет |
| *«Мия, какая загрузка процессора?»* | Проверяет загрузку CPU, RAM и свободное место на дисках |
| *«Мия, сделай потише / погромче»* | Плавно регулирует системную громкость Windows |
| *«Мия, закрой активное окно»* | Закрывает текущую программу |
| *«Мия, заблокируй компьютер»* | Мгновенно блокирует экран Windows (Win+L) |
| *«Дипсик, напиши скрипт на Python...»* | Передает сложную задачу мощной модели кодера DeepSeek |

## 🛠️ Возможные вопросы и устранение неполадок

<details>
<summary><b>1. Бот в Telegram не отвечает или выдает ошибку сети</b></summary>
В некоторых регионах прямой доступ к Telegram Bot API может блокироваться провайдером. В `config.py` уже встроено бесплатное Cloudflare Worker зеркало (`TG_API_SERVER`), работающее в РФ без всяких VPN. Если у тебя собственный прокси (v2rayN, Xray), ты можешь просто указать `TG_PROXY = "socks5://127.0.0.1:10809"`.
</details>

<details>
<summary><b>2. Мия не реагирует на голос или ложно срабатывает</b></summary>
Отрегулируй чувствительность микрофона в `config.py`:
- `HOTWORD_ENERGY_THRESHOLD = 0.0035`: уменьши значение (например, до `0.002`), если микрофон тихий, или увеличь (до `0.005`), если в комнате шумно.
</details>

<details>
<summary><b>3. Где взять ключ для эксперта DeepSeek / Кодера?</b></summary>
Для базовых задач локальная Ollama с моделью `qwen2.5:3b-instruct` работает абсолютно бесплатно и полностью офлайн. Для сложных вопросов по программированию ты можешь бесплатно получить токен на [platform.deepseek.com](https://platform.deepseek.com) или указать любой OpenAI-совместимый эндпоинт.
</details>
