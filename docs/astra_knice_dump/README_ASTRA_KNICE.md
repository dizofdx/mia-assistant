# Полный анализ и копия материалов сайта https://knice.tech/ (Astra AI)

## 1. О проекте Astra
**Слоган:** *«Знакомьтесь — Astra. Ваш ПК, с характером. Голосовой ИИ компаньон — управляет вашим компьютером, автоматизирует рутину и составляет отличную компанию.»*  
**Разработчик:** Minice (`minice.ai`, `contact@minice.ai`)  
**Платформы:** Windows 10/11 (64-bit), Linux (64-bit), Steam, мобильное приложение Astra Connect (iOS / Android) и Telegram-бот.

## 2. Структура страниц сайта
1. **Главная (`/`)**
   - **Hero секция:** Слоган, кнопки «Скачать» и «Что я умею?».
   - **Интерактивный макет приложения (Astra App Mockup):**
     - Окно десктопного приложения с Traffic-lights кнопками.
     - Верхние вкладки: `Главная`, `Команды`, `ИИ`, `Голос`, `Модель`, `Настройки`.
     - Виджет медиаплеера: обложка, название трека, таймлайн, кнопки управления.
     - Виджет погоды: температура, иконка солнца/погоды, описание.
     - Виджет курсов валют: USD/EUR, динамика в процентах.
     - Виджет системных ресурсов: CPU (%), RAM (% и ГБ), GPU (%).
     - Быстрые кнопки виджетов: Задачи (с бейджем счетчика), Календарь, Напоминания, Заметки.
     - Список недавних диалогов и живой чат с голосовой кнопкой и вводом сообщений.
   - **Режим ИИ-агента (`#ai-agent`):**
     - Визуальный граф вызова функций и цепочки мыслей: `files.search`, `reminders.add`.
     - Возможности агента: запуск приложений/сайтов, работа с файлами, создание автоматизаций, долговременная память, умный поиск в браузере, управление Windows API.
   - **Возможности (`#capabilities`):**
     - Свободный диалог на любую тему.
     - Инструменты на каждый день.
     - Пользовательские команды и сценарии.
     - Настройка роли, характера и внешности (Джарвис и др.).
     - Удаленное управление с телефона (Astra Connect / Telegram).
     - Голосовое и клавиатурное управление (хоткеи).
     - MCP-серверы (Model Context Protocol).
     - Плагины и маркетплейс дополнений.
   - **Виртуальная 3D/2D модель (`#virtual-model`):**
     - VRM-модель персонажа, живущая на рабочем столе, реагирующая на курсор и танцующая под музыку.
   - **Редактор команд (`#command-editor`):**
     - Нодовый визуальный конструктор сценариев (Триггеры -> Условия -> Действия -> Уведомления).
   - **Astra Connect и Telegram (`#astra-connect`):**
     - Управление компьютером удаленно через собственного Telegram-бота (голосовые и текст).
   - **Системные требования (`#requirements`):**
     - ОС: Windows 10/11 (64-bit), Linux (64-bit).
     - CPU: Intel Core i3-6100 / AMD Ryzen 3 1200 (AVX2).
     - GPU: GTX 750 Ti / Radeon R7 360 (DirectX 11/12).
     - RAM: 8 ГБ+.
   - **Цены и тарифы (`#pricing`):**
     - Разовая покупка полной версии: 849 ₽ навсегда.
     - Steam-версия.
     - Подписка Plus: 449 ₽ / 31 день (облачный ИИ + облачные голоса).
     - Подписка Pro: 1349 ₽ / 31 день (повышенные лимиты).
