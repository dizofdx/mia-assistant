Что умеет Мия?

Голосовое управление, автоматизация и развлечения — всё в одном приложении

🎙️

Голосовое управление

Скажи «Мия» — и она услышит. Распознавание речи Vosk + голос Silero TTS. Работает полностью офлайн.

🌐

Веб-панель Astra

Красивый веб-интерфейс с системным мониторингом, чатом, картой, управлением сценариями и 3D-аватаром.

🤖

Telegram-бот

Управляй ПК из любой точки мира. Скриншоты, голосовые сообщения, команды — всё через Telegram.

🎵

Музыка и медиа

Яндекс Музыка, YouTube, управление плеером — пауза, переключение треков, громкость голосом.

⚡

Сценарии и автоматизация

Создавай сценарии: «Отдых» откроет YouTube + запустит музыку. «Фокус» включит lo-fi для работы.

🗺️

Карта и погода

Интерактивная карта MapLibre GL с поиском городов и метеостанцией в реальном времени.

Технологии

Построена на современных Python-инструментах

🐍 Python 3.11 ⚡ FastAPI 🧠 Google Gemini AI 🎤 Vosk STT 🔊 Silero TTS v4 🤖 Telegram Bot API 🗺️ MapLibre GL 📱 PWA / Android 🖥️ PyAutoGUI 🎵 Media Control

🚀 Быстрая установка

Клонируй репозиторий, установи зависимости и запусти Мию за 2 минуты

# Клонируй репозиторий
git clone https://github.com/dizofdx/mia-assistant.git
cd mia-assistant

# Установи зависимости
pip install -r requirements.txt

# Запусти Мию
python main.py
