# Мия Connect — Мобильное приложение для Android (Astra Connect Style)

Данный каталог содержит всё необходимое для запуска и сборки мобильного приложения **Мия Connect** для Android, которое позволяет управлять ПК и общаться с Мией прямо со смартфона.

---

## 🚀 Способ 1: Установка в 1 клик через PWA (Рекомендуемый, без Android Studio)

Благодаря поддержке Progressive Web App (PWA), приложение устанавливается прямо из браузера как полноценное нативное приложение Android (с собственной иконкой на рабочем столе, полноэкранным режимом без адресной строки, доступом к микрофону и тактильной отдачей):

1. Убедитесь, что ваш компьютер и Android-смартфон подключены к **одному Wi-Fi роутеру**.
2. Узнайте локальный IP вашего ПК (по умолчанию: `http://192.168.0.100:8000`).
3. Откройте Google Chrome на телефоне и перейдите по адресу:
   ```
   http://192.168.0.100:8000
   ```
   *(Или отсканируйте QR-код во вкладке «Настройки» в веб-интерфейсе Мии на ПК)*.
4. В браузере появится баннер **«Установить приложение Мия Connect»** (или нажмите 3 точки в правом верхнем углу Chrome $\to$ **«Установить приложение»** / **«Добавить на главный экран»**).
5. На рабочем столе телефона появится приложение **Мия Connect** с фирменной кибер-иконкой!

---

## 📱 Возможности мобильного приложения:
* **Пульт ПК:**
  * Запуск и переключение Яндекс Музыки («Моя Волна», Пауза, След. трек).
  * Регулировка громкости ПК (Громче / Тише / Без звука).
  * Мгновенный скриншот экрана компьютера с просмотром прямо на телефоне.
  * Свернуть все окна и заблокировать ПК.
* **Голосовое и текстовое общение:**
  * Голосовой ввод с микрофона телефона.
  * Умные ответы Мии с озвучкой.
* **Мониторинг железа ПК в реальном времени:**
  * Загрузка процессора (CPU %).
  * Занятая и свободная оперативная память (RAM GB / %).
  * Свободное место на дисках C и D.
* **Визуальные команды:**
  * Запуск сценариев («YouTube lo-fi», «Режим фокуса», «Заблокировать ПК») одним нажатием.

## 🛠 Способ 2: Сборка автономного файла APK (через Capacitor)

Если вам нужен скомпилированный `.apk` файл для установки через проводник:
1. Установите Node.js (v18+) на ПК.
2. В папке `D:\assistant\android_app` выполните:
   ```bash
   npm install
   npx cap add android
   npx cap copy
   npx cap open android
   ```
3. В открывшемся Android Studio нажмите **Build $\to$ Build Bundle(s) / APK(s) $\to$ Build APK(s)**.
4. Полученный `.apk` файл можно скинуть на любой Android смартфон и установить.
